# Dependencies for the protocol simulators.
#
# Only modbus_simulator.py needs a third-party package. knx_simulator.py and
# dmx_artnet_simulator.py are pure standard library.
#
# pymodbus is pinned deliberately — do NOT float this version:
#
#   * >= 3.13 BREAKS modbus_simulator.py. ModbusSequentialDataBlock(0, ...)
#     internally became SimData(address - 1), so a block starting at address 0
#     raises "TypeError: 0 <= address < 65535" and the simulator exits at start-up.
#   * < 3.11 lacks ModbusDeviceContext / ModbusServerContext(devices=...),
#     which the simulator uses.
#   * 3.11.2 is what Home Assistant itself requires (see the modbus integration
#     manifest), so pinning here keeps the simulator and HA on one generation.
#
# Verified working: 3.10.0, 3.11.0, 3.11.2, 3.12.0
pymodbus==3.11.2
