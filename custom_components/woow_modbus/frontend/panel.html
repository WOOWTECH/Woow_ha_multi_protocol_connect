Modbus 設定指南

透過官方文檔 + AI 助手，輕鬆完成 Modbus 裝置 YAML 設定

1

📖 閱讀 Modbus 官方設定文檔

Modbus 是工業自動化中最廣泛使用的通訊協定。Home Assistant 內建 Modbus 整合支援， 涵蓋所有設定參數的說明。建議在開始設定前，先瀏覽官方文檔了解 Modbus 整合的基本架構，包含：

  • 連線方式 -- Modbus TCP (網路) 或 RTU (串列埠 RS-485/RS-232)
  • Slave ID -- 每個裝置的唯一識別編號 (1-247)
  • Register 類型 -- Coil、Discrete Input、Holding Register、Input Register
  • 資料型別 -- int16、uint16、int32、float32 等資料格式轉換
  • YAML 設定範例 -- 各種實體類型的設定範例與參數說明
前往 Modbus 官方文檔
2

🤖 使用 Woow AI 助手取得設定參數

閱讀官方文檔後，您可以透過我們提供的 AI 助手來取得針對您特定設備的 Modbus YAML 設定。 AI 助手能根據您的裝置型號、寄存器地址、資料型別與 Slave ID 等資訊，生成精確的設定內容。

使用方式：將您從官方文檔中了解到的參數需求，搭配您的實際設備資訊， 向 AI 助手詢問，即可獲得可直接使用的 YAML 設定。

前往 Woow AI 助手
3

📝 完整設定流程教學

以下是從零開始，透過官方文檔搭配 AI 助手完成 Modbus YAML 設定的完整步驟：

1
確認 Modbus 裝置資訊 從裝置手冊取得連線方式（TCP/RTU）、IP 或串列埠路徑、Slave ID、寄存器地址對照表。
2
瀏覽官方文檔 前往 HA Modbus 文檔，了解 YAML 設定的結構和各參數的意義。重點關注您需要的實體類型（如 sensor、switch、binary_sensor、climate 等）。
3
向 AI 助手提問

前往 Woow AI 助手，提供以下資訊以獲得設定建議：

‣ 裝置型號與連線方式（TCP IP:Port 或 RTU 串列埠路徑）
‣ Slave ID
‣ 要讀取的資料（溫度、濕度、電壓、電流等）
‣ 寄存器地址與資料型別

4
使用下方編輯器寫入 YAML 設定 將 AI 助手產生的 YAML 設定，透過下方的內建 YAML 編輯器直接編輯 configuration.yaml 或其他設定檔，無需額外安裝任何套件。
5
重新啟動 Home Assistant 儲存設定後，需要重新啟動 Home Assistant 以載入新的 Modbus 設定。請使用下方的重啟按鈕或至 設定 → 系統 → 重新啟動。
6
驗證裝置與實體 重啟後，前往 開發者工具 → 狀態 確認 Modbus 實體已正確載入並顯示數據。您也可以在 設定 → 裝置與服務 → Modbus 中查看整合狀態。

YAML 設定範例（以 Modbus TCP 裝置為例）：

💡 Modbus 為 HA 內建整合

Modbus 是 Home Assistant 內建整合，無需透過 HACS 安裝。直接在 YAML 中設定即可使用。

# configuration.yaml -- Modbus 設定範例 modbus: - name: "main_hub" type: tcp host: 192.168.1.200 port: 502 sensors: - name: "室內溫度" slave: 1 address: 0 input_type: input data_type: int16 scale: 0.1 unit_of_measurement: "°C" device_class: temperature switches: - name: "設備開關" slave: 1 address: 0 write_type: coil

完成！透過以上步驟，您已成功透過官方文檔參考與 AI 助手協作， 完成了 Modbus 裝置的 YAML 設定。設定生效後，您就可以在 Home Assistant 中監控和管理 Modbus 裝置與實體了。

🔄 重新啟動 Home Assistant

修改 configuration.yaml 後，必須重新啟動 Home Assistant 才能使設定生效。 新增的 Modbus 裝置與實體將在重啟後出現。

⚠️ 重要警告

重新啟動 Home Assistant 將會暫時中斷所有自動化、裝置連線與服務。 請確認以下事項後再執行：

  • 所有 YAML 設定已正確儲存，且格式無誤
  • 目前沒有關鍵的自動化正在執行中
  • 已通知家中成員系統將短暫無法使用
  • 建議在非尖峰時段執行重啟操作
💡 提示

如果只是修改了自動化或腳本，可以嘗試使用 設定 → 系統 → 重新載入 中的「重新載入 YAML」功能， 這不需要完全重啟系統。但 Modbus 裝置的新增或修改，通常需要完整重啟。
