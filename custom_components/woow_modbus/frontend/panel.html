📖 Read Modbus Official Documentation

Modbus is the most widely used communication protocol in industrial automation. Home Assistant has built-in Modbus integration support covering all configuration parameters. Before starting, review the official docs to understand the Modbus integration architecture, including:

  • Connection Methods -- Modbus TCP (network) or RTU (serial RS-485/RS-232)
  • Slave ID -- Unique identification number for each device (1-247)
  • Register Types -- Coil, Discrete Input, Holding Register, Input Register
  • Data Types -- Data format conversions: int16, uint16, int32, float32, etc.
  • YAML Examples -- Configuration examples and parameter descriptions for various entity types

📝 Complete Setup Tutorial

Follow these steps to complete Modbus YAML configuration from scratch using official docs and AI assistant:

1
Confirm Modbus Device Info From the device manual, obtain the connection method (TCP/RTU), IP or serial port path, Slave ID, and register address mapping table.
2
Browse Official Documentation Visit HA Modbus Documentation to understand the YAML structure and parameter meanings. Focus on the entity types you need (e.g., sensor, switch, binary_sensor, climate, etc.).
3
Ask the AI Assistant

Visit Woow AI Assistant and provide the following information for configuration suggestions:

‣ Device model and connection method (TCP IP:Port or RTU serial port path)
‣ Slave ID
‣ Data to read (temperature, humidity, voltage, current, etc.)
‣ Register addresses and data types

4
Use the Editor Below to Write YAML Configuration Paste the AI-generated YAML configuration into the built-in YAML editor below to directly edit configuration.yaml or other config files, without installing any additional packages.
5
Restart Home Assistant After saving, restart Home Assistant to load the new Modbus configuration. Use the restart button below or go to Settings → System → Restart.
6
Verify Devices and Entities After restarting, go to Developer Tools → States to confirm Modbus entities loaded correctly and are showing data. You can also check integration status in Settings → Devices & Services → Modbus.

YAML Configuration Example (Modbus TCP Device):

💡 Modbus is a built-in HA integration

Modbus is a built-in Home Assistant integration, no HACS installation required. Simply configure it in YAML to use.

# configuration.yaml -- Modbus 設定範例 modbus: - name: "main_hub" type: tcp host: 192.168.1.200 port: 502 sensors: - name: "室內溫度" slave: 1 address: 0 input_type: input data_type: int16 scale: 0.1 unit_of_measurement: "°C" device_class: temperature switches: - name: "設備開關" slave: 1 address: 0 write_type: coil

Done! By following the steps above, you have successfully completed the Modbus device YAML configuration using official documentation and AI assistant collaboration. After the settings take effect, you can monitor and manage Modbus devices and entities in Home Assistant.

🔄 Restart Home Assistant

After modifying configuration.yaml, you must restart Home Assistant for changes to take effect. New Modbus devices and entities will appear after restart.

⚠️ Important Warning

Restarting Home Assistant will temporarily interrupt all automations, device connections, and services. Please confirm the following before proceeding:

  • All YAML configurations have been saved correctly with proper formatting
  • No critical automations are currently running
  • Household members have been notified of temporary system unavailability
  • It is recommended to restart during off-peak hours
💡 Tip

If you only modified automations or scripts, try using the "Reload YAML" function in Settings → System → Reload, which doesn't require a full restart. However, adding or modifying Modbus devices usually requires a complete restart.
