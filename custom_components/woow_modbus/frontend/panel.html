Woow Modbus 設定指南

透過官方文檔 + AI 助手，輕鬆完成 Modbus 裝置 YAML 設定

📖 Step 1：閱讀 Modbus 官方設定文檔

Modbus 是工業自動化中最常用的通訊協議之一，Home Assistant 內建完整的 Modbus 整合支援。 在開始設定前，請了解以下基本概念：

  • Modbus TCP — 透過網路 (TCP/IP) 連接 Modbus 裝置，需要 IP 和埠號
  • Modbus RTU — 透過串列埠 (RS-485/RS-232) 連接，需要串列裝置路徑
  • Slave ID — 每個 Modbus 裝置的唯一識別編號 (1-247)
  • Register 類型 — Coil (線圈)、Discrete Input (離散輸入)、Holding Register (保持寄存器)、Input Register (輸入寄存器)
  • Register 地址 — 每個資料點的寄存器地址（通常由裝置手冊提供）
前往 Modbus 官方文檔

🤖 Step 2：使用 Woow AI 助手取得設定參數

透過 Woow AI 助手，您可以根據特定的 Modbus 裝置型號和通訊協議， 快速生成正確的 YAML 設定。AI 助手能幫助您：

  • 判斷使用 Modbus TCP 或 RTU 連線方式
  • 正確設定 Slave ID 和寄存器地址
  • 配置感測器、開關、氣候控制等實體類型
  • 處理資料型別轉換（int16、uint32、float 等）
  • 設定掃描間隔和錯誤處理
前往 Woow AI 助手

📝 Step 3：完整 Modbus 設定流程教學

以下是從零開始完成 Modbus 裝置設定的完整步驟：

1
確認 Modbus 裝置資訊 從裝置手冊取得：連線方式（TCP/RTU）、IP 或串列埠路徑、Slave ID、寄存器地址對照表。
2
瀏覽官方文檔 前往 HA Modbus 文檔，了解 YAML 設定結構。重點關注您需要的實體類型（sensor、switch、climate、binary_sensor 等）。
3
向 AI 助手提問 前往 Woow AI 助手，提供以下資訊：
‣ 裝置型號和品牌
‣ 連線方式（TCP IP:Port 或 RTU 串列埠路徑）
‣ Slave ID
‣ 需要讀取的資料（溫度、濕度、電壓、電流等）
‣ 寄存器地址（如有手冊提供）
4
使用下方編輯器寫入 YAML 設定 將 AI 助手產生的 YAML 設定，透過下方的內建 YAML 編輯器直接編輯 configuration.yaml。
5
重新啟動 Home Assistant 儲存設定後，重新啟動 Home Assistant 以載入 Modbus 設定。
6
驗證裝置與實體 重啟後，前往 開發者工具 → 狀態 查看 Modbus 實體是否正確讀取資料。

YAML 設定範例（Modbus TCP 感測器）：

💡 注意：Modbus 為 HA 內建整合

Modbus 是 Home Assistant 內建整合，無需額外安裝。直接在 YAML 中設定即可使用。

# configuration.yaml — Modbus 設定範例
modbus:
  - name: "main_hub"
    type: tcp
    host: 192.168.1.200
    port: 502

    sensors:
      - name: "室內溫度"
        slave: 1
        address: 0
        input_type: input
        count: 1
        data_type: int16
        scale: 0.1
        unit_of_measurement: "°C"
        device_class: temperature

      - name: "室內濕度"
        slave: 1
        address: 1
        input_type: input
        count: 1
        data_type: int16
        scale: 0.1
        unit_of_measurement: "%"
        device_class: humidity

    switches:
      - name: "空調開關"
        slave: 1
        address: 0
        write_type: coil

完成！透過以上步驟，您已成功設定 Modbus 裝置連線。 現在可以在 Home Assistant 中監控和控制 Modbus 裝置，並建立自動化規則。
