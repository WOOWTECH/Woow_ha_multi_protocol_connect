Woow DMX 設定指南

透過官方文檔 + AI 助手，輕鬆完成 DMX 燈光控制 YAML 設定

📖 Step 1：了解 DMX 燈光控制協議

DMX512 是專業燈光控制的標準協議，廣泛應用於舞台燈光、建築照明和智慧家居場景。 在 Home Assistant 中，您可以透過 ArtNet 或 sACN (E1.31) 來控制 DMX 裝置：

  • ArtNet — 透過網路 (UDP) 傳送 DMX 訊號至 ArtNet 節點
  • sACN / E1.31 — 基於 ACN 標準的串流 DMX 資料協議
  • DMX Universe — 每個 Universe 可控制最多 512 個通道
  • 通道地址 — 每個燈具佔用一個或多個 DMX 通道（如 RGB 燈具佔用 3 個通道）
DMX 整合文檔 (hass-dmx) Flux LED 官方文檔

🤖 Step 2：使用 Woow AI 助手取得 DMX 設定

透過 Woow AI 助手，您可以根據實際的 DMX 裝置型號、通道配置等資訊， 生成對應的 YAML 設定。AI 助手能幫助您正確配置：

  • DMX Universe 編號與網路介面設定
  • 每個燈具的起始通道地址
  • 燈具類型（調光器、RGB、RGBW、移動燈等）
  • 轉換效果（淡入淡出時間、預設亮度等）

📝 Step 3：完整 DMX 設定流程教學

以下是從零開始完成 DMX 燈光控制設定的完整步驟：

1
確認 DMX 硬體資訊 記下您的 ArtNet 節點 IP 位址（或 sACN 多播設定）、Universe 編號，以及每個燈具的起始 DMX 通道地址。
2
安裝 DMX 整合 Home Assistant 可透過 HACS 安裝 hass-dmx 整合套件，支援 ArtNet 和 sACN 協議。
3
向 AI 助手提問 前往 Woow AI 助手，提供以下資訊：
‣ DMX 節點類型（ArtNet / sACN）與 IP 位址
‣ 燈具類型（調光器、RGB、RGBW、色溫燈等）
‣ 起始通道地址與 Universe 編號
4
使用下方編輯器寫入 YAML 設定 將 AI 助手產生的 YAML 設定，透過下方的內建 YAML 編輯器直接編輯 configuration.yaml。
5
重新啟動 Home Assistant 儲存設定後，重新啟動 Home Assistant 以載入 DMX 燈光設定。
6
測試燈光控制 前往 開發者工具 → 服務，呼叫 light.turn_on 測試 DMX 燈光是否正常回應。

YAML 設定範例（ArtNet DMX 燈光）：

💡 注意：需先安裝 hass-dmx 整合

DMX 控制需透過 HACS 安裝 hass-dmx 整合套件。安裝後才能使用以下 YAML 設定。

# configuration.yaml — DMX 燈光設定範例
light:
  - platform: dmx
    host: 192.168.1.100 # ArtNet 節點 IP
    port: 6454 # ArtNet 預設埠
    dmx_channels: 512
    default_level: 0
    universe: 0
    devices:
      - channel: 1
        name: "客廳主燈"
        type: dimmer
        transition: 1

      - channel: 2
        name: "氣氛 RGB 燈條"
        type: rgb
        transition: 2

      - channel: 5
        name: "走廊射燈"
        type: dimmer
        default_level: 128

完成！透過以上步驟，您已成功設定 DMX 燈光控制。 現在可以在 Home Assistant 中控制所有 DMX 燈具，並建立自動化場景。
