KNX 設定指南

透過官方文檔 + AI 助手，輕鬆完成 KNX 裝置 YAML 設定

1

📖 閱讀 KNX 官方設定文檔

Home Assistant 官方提供了完整的 KNX 整合文檔，涵蓋所有設定參數的說明。 建議在開始設定前，先瀏覽官方文檔了解 KNX 整合的基本架構，包含：

  • 連線設定 -- KNX/IP Gateway 或 Tunneling 的連線方式
  • Group Address -- 群組地址的對應與格式
  • 裝置類型 -- 支援的實體類型（light, switch, cover, climate, sensor 等）
  • YAML 設定範例 -- 各種裝置的設定範例與參數說明
前往 KNX 官方文檔
2

🤖 使用 Woow AI 助手取得設定參數

閱讀官方文檔後，您可以透過我們提供的 AI 助手來取得針對您特定設備的 KNX YAML 設定。 AI 助手能根據您的裝置型號、群組地址等資訊，生成精確的設定內容。

使用方式：將您從官方文檔中了解到的參數需求，搭配您的實際設備資訊， 向 AI 助手詢問，即可獲得可直接使用的 YAML 設定。

前往 Woow AI 助手
3

📝 完整設定流程教學

以下是從零開始，透過官方文檔搭配 AI 助手完成 KNX YAML 設定的完整步驟：

1
確認 KNX 硬體資訊 記下您的 KNX/IP Gateway IP 位址、埠號，以及每個裝置對應的 Group Address。
2
瀏覽官方文檔 前往 HA KNX 文檔，了解 YAML 設定的結構和各參數的意義。重點關注您需要的裝置類型（如 light、switch、climate 等）。
3
向 AI 助手提問

前往 Woow AI 助手，提供以下資訊以獲得設定建議：

‣ 裝置類型（燈具、開關、窗簾、溫控等）
‣ Group Address（如 1/0/1）
‣ 需要的功能（調光、狀態回報、溫度讀取等）

4
透過 UI 新增 KNX 整合（連線設定） 前往 設定 → 裝置與服務 → 新增整合，搜尋「KNX」並依指示輸入 Gateway IP 與連線方式（Tunneling / Routing）。此步驟僅需執行一次。
5
使用下方編輯器寫入 YAML 設定 將 AI 助手產生的 YAML 設定，透過下方的內建 YAML 編輯器直接編輯 configuration.yaml 或其他設定檔，無需額外安裝任何套件。
6
重新啟動 Home Assistant 儲存設定後，需要重新啟動 Home Assistant 以載入新的 KNX 設定。請使用下方的重啟按鈕或至 設定 → 系統 → 重新啟動。
7
驗證裝置與實體 重啟後，前往 設定 → 裝置與服務 → KNX 確認裝置已正確載入。您也可以在 開發者工具 → 狀態 中查看新建立的實體狀態。

💡 注意：連線設定需透過 UI

在新版 Home Assistant 中，KNX 的連線設定（Tunneling / Routing）需透過 設定 → 裝置與服務 → 新增整合 → KNX 介面完成。
YAML 僅用於定義裝置與實體，連線參數不再寫在 configuration.yaml 中。

# configuration.yaml -- 僅定義裝置（連線透過 UI 設定） knx: light: - name: "客廳主燈" address: "1/0/1" state_address: "1/0/2" brightness_address: "1/0/3" brightness_state_address: "1/0/4" switch: - name: "玄關開關" address: "2/0/1" state_address: "2/0/2" sensor: - name: "室內溫度" state_address: "3/0/1" type: "temperature"

完成！透過以上步驟，您已成功透過官方文檔參考與 AI 助手協作， 完成了 KNX 裝置的 YAML 設定。設定生效後，您就可以在 Home Assistant 中控制和管理 KNX 裝置與實體了。

🔄 重新啟動 Home Assistant

修改 configuration.yaml 後，必須重新啟動 Home Assistant 才能使設定生效。 新增的 KNX 裝置與實體將在重啟後出現。

⚠️ 重要警告

重新啟動 Home Assistant 將會暫時中斷所有自動化、裝置連線與服務。 請確認以下事項後再執行：

  • 所有 YAML 設定已正確儲存，且格式無誤
  • 目前沒有關鍵的自動化正在執行中
  • 已通知家中成員系統將短暫無法使用
  • 建議在非尖峰時段執行重啟操作
💡 提示

如果只是修改了自動化或腳本，可以嘗試使用 設定 → 系統 → 重新載入 中的「重新載入 YAML」功能， 這不需要完全重啟系統。但 KNX 裝置的新增或修改，通常需要完整重啟。
